About File Converter

File Converter is a browser-based image conversion tool. It accepts JPEG, PNG, WebP, GIF, BMP and AVIF images where supported by your browser, and produces JPG, PNG, WebP, BMP or a single-page PDF for each input.

How conversion works

The browser decodes the image, draws its pixels onto a canvas and encodes the result in your selected format. You can select several files and download each result. The tool leaves your original files as they were.

Supported sizes

Each input can be up to 25 MB, 8,192 pixels on either side and 32 million pixels in total. If a phone or browser runs out of memory, try a smaller image or convert one file at a time. Animated files produce a still image.

Support and bug reports

Email 5star.top11@gmail.com for support. Include your browser, input format, output format, and any error shown.

Additional output formats

Choose ICO for icons up to 256 pixels, TIFF for uncompressed images, or TGA and QOI for graphics with transparency. Choose PPM if your software expects raw RGB pixel data.
