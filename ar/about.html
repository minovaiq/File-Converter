عن محوّل الملفات

محوّل الملفات أداة تعمل داخل المتصفح. تقبل صور JPEG وPNG وWebP وGIF وBMP وAVIF حسب دعم متصفحك، وتخرج JPG أو PNG أو WebP أو BMP أو ملف PDF من صفحة واحدة لكل صورة.

كيف يعمل التحويل؟

يقرأ المتصفح الصورة ويرسمها ثم يحفظ النتيجة بالصيغة المختارة. يمكنك إضافة عدة صور وتنزيل كل نتيجة على حدة. تبقى الملفات الأصلية على جهازك كما هي.

حدود الحجم والأبعاد

الحد لكل صورة 25 ميغابايت و8,192 بكسل لكل ضلع و32 مليون بكسل إجمالاً. إذا تعذّر التحويل بسبب ذاكرة الجهاز، جرّب صورة أصغر أو حوّل الصور واحدة تلو الأخرى. تتحول الصور المتحركة إلى صورة ثابتة.

الدعم والإبلاغ عن خطأ

أرسل بلاغك عبر GitHub Issues. اذكر المتصفح وصيغة الصورة الأصلية وصيغة الإخراج ورسالة الخطأ. استخدم صورة تجريبية عامة إذا احتجت إرفاق مثال.
